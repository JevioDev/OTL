# Contributing

Keep changes focused on design judgment for coding agents.

Before opening a pull request:

- explain the failure mode or user need the change addresses;
- preserve progressive disclosure and framework independence;
- avoid turning a style preference into a permanent ban;
- run the skill validator when available and check links and frontmatter;
- update the README when the public workflow or identity changes.

For reference changes, say which agent decision the guidance changes and why the existing wording was insufficient.
