# Anti-Slop and Similarity Resistance

Anti-slop means detecting decisions produced by habit instead of product-specific reasoning. It does not mean swapping one popular aesthetic for another. Use this reference as a diagnostic during planning and after the first rendered pass.

## Smell test

For each item, ask whether it is carrying information, interaction, brand meaning, or useful pacing. If not, remove or replace it.

| Pattern | Reconsider when | Keep when |
| --- | --- | --- |
| Every group is a rounded card | spacing or hierarchy would communicate the group | content is independently scannable, selectable, movable, or bounded |
| Cards nested inside cards | the inner boundary adds no new state or relationship | distinct ownership, state, or interaction genuinely needs it |
| Three equal feature cards | the content has no equal three-part structure | the product actually offers three comparable choices or capabilities |
| Centered hero with giant title and two buttons | it is only the agent's default landing pattern | the user needs a single centered decision or the subject is intentionally staged |
| Gradient, glow, mesh, or glass | it fills space without semantic or brand evidence | it explains material, depth, changing content, or a documented brand behavior |
| Random monospace, tiny labels, or all caps | the text is not machine data, taxonomy, or a real interface convention | the treatment improves scanning or encodes meaning |
| 01 / 02 / 03 markers | content is not sequential | the content is a real process, timeline, or ordered set |
| Pills everywhere | the control is not a compact choice, status, filter, or tag | the shape improves recognition and hit target behavior |
| Generic icon tiles and decorative arrows | the icon does not improve wayfinding or action clarity | it represents a real object, state, or directional relationship |
| Muted text used for most content | hierarchy depends on making content hard to read | secondary content is genuinely secondary and still legible |
| Fade-up and hover motion everywhere | nothing changed that needs explanation | a specific transition explains causality or supports expression |
| Dashboard chrome on a non-operational product | panels and metrics are ornamental | users actually monitor, compare, or operate live information |
| Fake data, stats, or trust badges | the numbers do not represent real evidence | the product has real, relevant evidence with a clear source |
| Identical section rhythm and bento grids | composition is repeated without meaning | the content has repeated structure that benefits from it |

The same decision can pass or fail in different products. Record the reason rather than maintaining a blacklist.

## Similarity audit

Compare the current work with the agent's recent outputs or the project's existing surfaces. Check for repeated:

- hero composition and alignment;
- type pairing and hierarchy;
- background treatment and accent strategy;
- section order and repeated block shapes;
- icon and button silhouettes;
- motion choreography and easing;
- card radius, border, and shadow behavior.

Repetition is acceptable when it belongs to a shared product system. It is suspicious when it appears across unrelated products with different content and audiences.

Ask: "Would the agent make the same choice for an unrelated product?" A yes answer triggers a second look, not an automatic rejection.

## Correction pass

After the first rendered review:

1. name the strongest product-specific signal;
2. name the most generic-looking decision;
3. remove one decoration that has no job;
4. strengthen one hierarchy or content relationship;
5. verify that the change did not create a new visual gimmick.

Specificity is the goal, not novelty for its own sake.
